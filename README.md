# NASA API Tests

Учебный проект для изучения **pytest** и автоматизации тестирования REST API на Python.

## Стек

- Python
- pytest
- Requests
- python-dotenv

## Что проверяется

- **APOD (Astronomy Picture of the Day)** — астрономическая фотография дня.
- **NeoWs** — данные о сближающихся с Землей астероидах.
- **NASA Image and Video Library** — поиск изображений и метаданных.
- **NASA Exoplanet Archive** — данные об экзопланетах.

Тесты проверяют успешность запросов, структуру JSON-ответов, наличие обязательных полей и корректность типов данных.

## Установка и запуск

1. Клонировать репозиторий и перейти в папку проекта.

```bash
  git clone https://github.com/Tr-Veronika/nasa-api-pytest.git
  cd nasa-api-pytest
```

2. Создать виртуальное окружение и активировать его:

```bash
  python -m venv .venv
  .venv\Scripts\Activate.ps1
```

3. Установить зависимости из `requirements.txt`:

```bash
  pip install -r requirements.txt
```

4. Создать файл `.env` в корне проекта и добавить API-ключ NASA:

```text
  NASA_API_KEY=your_api_key
```

Получить ключ можно на официальном сайте: [NASA API Portal](https://api.nasa.gov/).

5. Запустить тесты:

```bash
  pytest -v
```

## Используемые фикстуры

В проекте используются фикстуры pytest, которые выполняют API-запросы и предоставляют данные тестам.

- `apod_data` — получает данные Astronomy Picture of the Day (APOD) за указанную дату.
    
- `neo_data` — получает данные об околоземных объектах (NeoWs) за указанную дату.
    
- `image_search_data` — получает результаты поиска в NASA Image and Video Library по запросу `apollo`.
    
- `exoplanet_data` — получает список подтверждённых экзопланет из NASA Exoplanet Archive.
    

Фикстуры имеют область действия `module`, поэтому результат запроса используется повторно в пределах одного тестового модуля.

## Цель проекта

Практика работы с pytest для автоматизации тестирования API на Python:

- работу с HTTP-запросами и JSON
- применение pytest для организации тестов
- использование фикстур и областей их действия
- проверку структуры и типов данных
- проверку позитивных и негативных сценариев
- работу с переменными окружения
- анализ HTTP-ошибок и диагностику проблем интеграции
